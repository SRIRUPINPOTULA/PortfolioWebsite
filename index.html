AWS Face-Recognition Framework

A Flask front end (S3 upload + SQS enqueue) with a PyTorch backend and custom EC2 autoscaling (0–15 instances) tuned for sub-second latency at 100 concurrent requests. Containerized MTCNN detection and InceptionResnetV1 recognition Lambdas to ECR, and deployed a dual-EC2 Greengrass v2 edge environment with SQS-triggered FaceNet inference — 100% accurate at under 0.8s latency.

Systems-level work on the xv6 teaching OS (RISC-V): built a secure bootloader with SHA-256 validation and PMP memory protection, implemented demand paging, FIFO page swapping, and Copy-on-Write fork(). Wrote ULTLib for user-level threads with round-robin, FCFS, and priority scheduling plus assembly context switching, and a trap-and-emulate virtual machine monitor for privileged instructions.
